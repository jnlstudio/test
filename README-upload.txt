上載方法
1. 解壓 ZIP。
2. 將 index.html、style.css、app.js、assets 資料夾及其他檔案放入 test 儲存庫根目錄，覆蓋同名檔案。不要只上載 ZIP，亦不要多包一層資料夾。
3. 保留現有 GitHub Pages 發布設定，等發布完成。
4. 開啟 https://jnlstudio.github.io/test/ ，如仍見舊版，強制重新整理。
